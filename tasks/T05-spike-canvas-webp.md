## 目的

仕様書 付録 A の値は cwebp での見積もり。実際のブラウザの canvas でどれだけずれるかを確かめ、画質探索の既定値(画質 0.60〜0.92、0.8 倍ずつ縮小)が妥当かを判断する。

## 作業内容

- [ ] 静的な HTML ページと Playwright で、写真を長辺(1600 / 1280 / 1024 / 800)× 画質(0.60〜0.92)でエンコードし、サイズを記録する(Chromium・Firefox)
- [ ] 同じ条件の cwebp の結果と比べる
- [ ] エンコード1回あたりの時間も記録する(1枚の処理時間の見積もりに使う)

## 完了条件

- [ ] 結果をこのノートの「結果」に根拠レベル付きで記録した
